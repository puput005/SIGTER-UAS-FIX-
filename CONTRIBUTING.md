# Panduan Kontribusi

Terima kasih sudah tertarik berkontribusi ke KosFinder.

## Cara Berkontribusi

1. Fork repository ini.
2. Buat branch baru:

```bash
git checkout -b fitur/nama-fitur
```

3. Lakukan perubahan pada file yang diperlukan.
4. Uji website menggunakan Live Server.
5. Commit perubahan:

```bash
git commit -m "Menambahkan fitur ..."
```

6. Push branch dan buat Pull Request.

## Area yang Bisa Dikembangkan

- Validasi data kos.
- Login admin untuk edit/hapus data.
- Tampilan mobile.
- Filter tambahan.
- Rute ke Google Maps.
- Integrasi database Supabase.
- Perbaikan data GeoJSON.

## Standar Kode

- Gunakan HTML, CSS, dan JavaScript yang mudah dibaca.
- Hindari perubahan besar yang tidak berhubungan dengan fitur.
- Jangan memasukkan API key rahasia.
- Jika mengubah data, jelaskan sumber data atau beri catatan bahwa data masih dummy.

## Catatan Data

Data kos dalam project ini dapat berupa data dummy untuk praktikum. Jangan memakai data pribadi atau kontak asli tanpa izin.
