# Code of Conduct

Project ini terbuka untuk pembelajaran dan kolaborasi.

Semua kontributor diharapkan:

- Menggunakan bahasa yang sopan.
- Menghargai pendapat dan latar belakang orang lain.
- Memberi kritik secara jelas dan membangun.
- Tidak melakukan pelecehan, ancaman, doxing, spam, atau diskriminasi.
- Tidak memasukkan data pribadi tanpa izin.

Jika ada masalah dalam kontribusi, diskusikan melalui issue atau pull request dengan bahasa yang baik.
